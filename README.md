# Tranajo-Is
Repositorio para hacer la practicas de Is

Como ejecutar la página?:
-En la terminal, navegar hasta la carpeta dobde está el repositorio
-En linux, meter en la terminal el siguiente comando: g++ main.cpp -o servidor -std=c++17 -lpthread
-En windows, se requiere de MSYS2, una vez instalado abrir MSYS2 UCRT64, asegurarse de que el compilaodr g++ más reciente y ejecutar el siguiente comando: g++ main.cpp -o servidor.exe -std=c++17 -lws2_32
-Una vez ejecutado el comando, se debera de haber creado un ejecutable nombrado servidor.exe
-Ejecutar dicho ejecutable e irse a http://localhost:8080 en el navegador
